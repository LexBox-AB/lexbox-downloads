# LexBox downloads

Officiella pilotpaket för LexBox.

**Installationsguider:** https://start.lexbox.se

Hämta aktuella filer från [Releases](https://github.com/LexBox-AB/lexbox-downloads/releases). Paketen är pilotversioner; se versionsinformationen för plattformsstöd och begränsningar. API-nycklar tillhandahålls separat av LexBox.

Ingen kundinformation eller API-nyckel ska läggas i det här offentliga repot.
